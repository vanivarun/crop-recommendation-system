Assets folder
=============

Place local crop images here to display in the Streamlit app without network calls.

Naming convention
- Use the crop common name as the filename, for example `rice.jpg`, `maize.png`, `apple.jpeg`.
- Lowercase filenames are recommended.

Supported extensions: `.jpg`, `.jpeg`, `.png`.

Image guidance
- Use reasonably small images (e.g., 800x600 or smaller) to keep app responsive.

Example:

assets/
  ├─ rice.jpg
  └─ maize.png
